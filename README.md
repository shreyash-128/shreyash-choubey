# Personal Portfolio

A personal portfolio website built to showcase my projects, technical skills, achievements, and learning journey as a Computer Engineering student.

## Features

- Responsive layout for desktop and mobile
- Dark theme with orange accents
- Project details and GitHub links
- Skills and achievements sections
- Interactive 3D visual built with Three.js
- Contact and social profile links

## Technologies Used

| Technology | Usage in the Portfolio |
|---|---|
| HTML5 | Structure of the Hero, About, Projects, Skills, Achievements, and Contact sections |
| CSS3 | Custom styling, responsive layouts, hover effects, and animations |
| Tailwind CSS | Utility classes for layout, spacing, colours, and typography |
| JavaScript | UI interactions, scroll behaviour, and animation controls |
| Three.js | Interactive 3D cube and monolith visual |
| Google Fonts | Archivo Narrow, Hanken Grotesk, and JetBrains Mono |
| Material Symbols | Icons used throughout the interface |

## Project Structure

- `index.html` — Main page structure
- `css/style.css` — Custom styles and responsive rules
- `js/main.js` — General interface interactions
- `js/monolith.js` — Three.js scene and animation logic
- `assets/images/` — Portfolio images

## Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.

The project uses CDN-hosted libraries and fonts, so an internet connection is required for those resources.
